PoB Per-Skill Cache Comparison Implementation Plan

Goal: compare PoB's cached output for one skill with one support gem enabled and disabled.

Architecture: extend AgentMechanismTool.lua with a cache reader and a protected toggle/rebuild/restore operation. Reuse cacheSkillUUID, GlobalCache, and CalcsTab:BuildOutput().

Tech stack: Lua/LuaJIT, existing PoB runtime, assert-based tests.

Global constraints

  • No PoB calculation source edits.
  • No formula reimplementation.
  • All temporary mutations restore on success and error.
  • Missing cache/output fields remain unavailable.

File: src/Modules/AgentMechanismTool.lua
