Skill Set Chain Query Implementation Plan

Goal: query a named Skill Set and read PoB's calculated chain outputs for a named skill.

Architecture: extend AgentMechanismTool.lua with selector, skill lookup, context save/restore, and chain extraction. Reuse PoB's CalcsTab:BuildOutput(); do not duplicate formulas.

Tech stack: Lua/LuaJIT, existing PoB runtime, assert-based tests.

Global constraints

  • No calculation-module edits.
  • Temporary context must be restored on success and error.
  • Exact skill matches only; ambiguous matches return an error.
