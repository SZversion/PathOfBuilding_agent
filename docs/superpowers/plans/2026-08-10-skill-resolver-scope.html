Skill Resolver Scope

Goal

Resolve a Skill Set selector and skill name to the corresponding PoB socket group and calculated active-skill index.

In scope

  • Case-insensitive title/name matching.
  • Skill Set title or numeric order selection.
  • Socket-group activation and PoB recalculation through existing methods.
  • Deterministic missing/ambiguous errors.

Out of scope

  • Natural-language fuzzy matching, translation, gem recommendation, or damage simulation.

Contract

find_skill(build, selector, name) -> { skillSet, socketGroup, skillIndex } | nil, error
