Skill Set Chain Query

Status: Approved for implementation

Branch: feat/pob-agent-architecture

Goal

Find a named PoB Skill Set and skill, calculate it in the correct temporary context, and expose PoB's existing chain outputs without inventing a new formula.

In scope

  • Add read-only-at-rest query functions to AgentMechanismTool.lua.
  • Resolve Skill Sets by exact title or 1-based order.
  • Resolve a skill by granted-effect name or base name, case-insensitively.
  • Temporarily switch skillsTab.activeSkillSetId, build.mainSocketGroup, and calcsTab.input.skill_number, call calcsTab:BuildOutput(), then restore and recalculate the original context.
  • Read Chain, ChainMax, ChainRemaining, and ChainMaxString from the selected active skill output.
  • Return the standard Fact Envelope and propagate failures as nil, error.

Out of scope

  • New chain formulas or combat simulation.
  • UI, model, server, routing, RAG, or database changes.
  • Persistent mutation of the loaded build.
  • Guessing a skill when multiple exact matches exist.

Contract

get_skill_set(build, selector) -> envelope | nil, error
get_skill_chain(build, skillSetSelector, skillName) -> envelope | nil, error

get_skill_chain.facts = {
  skillSet = { id, title, order },
  skill = { name, socketGroup, skillIndex },
  chain = { Chain, ChainMax, ChainRemaining, ChainMaxString }
}

Acceptance criteria

  • Original active Skill Set and selected skill are restored after success or error.
  • Fake test verifies title resolution, exact skill resolution, chain keys, and restoration.
  • External pcob leveling.xml smoke test queries 6) endgame setup and Poisonous Concoction of Bouncing; a calculated chain is printed, or an explicit unavailable reason is printed when PoB marks the skill disabled.
