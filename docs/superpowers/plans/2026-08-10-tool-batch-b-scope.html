Tool Batch B Scope

Goal

Expose direct skill behavior fields already calculated by PoB.

Contracts

  • get_projectile_behavior(build, skillIndex): facts {skillIndex,name,values}, where values contains present numeric keys from ProjectileCount,PierceCount,Chain,ChainMax,ChainRemaining,ForkCount,SplitCount; no values is nil,error.
  • get_trigger_sequence(build, skillIndex): facts {skillIndex,name,trigger,triggered,infoTrigger}, where trigger and infoTrigger are the string skill.infoTrigger when present and triggered is the boolean skill.triggered == true; absent fields remain nil, while a missing skill is nil,error.
  • get_curse_application_order(build, skillSetSelector, skillName): facts {status="not_simulated",basis="socket order only",gems}, reusing the existing socket resolver; it must never claim a simulated order.
  • get_ailment_effect(build, skillIndex): facts {skillIndex,name,values} for present numeric output keys ending in Chance or containing Ailment; no values is nil,error.

Allowed files and completion

Modify src/Modules/AgentTool.lua, agent/orchestration/agent_loop.py only to extend its Tool allowlist, the focused Lua self-check, and this plan. No formula changes; all four success/error contracts must pass.
