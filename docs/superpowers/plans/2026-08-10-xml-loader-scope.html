XML Loader Scope

Goal

Load one user-selected PoB XML file into an in-memory PoB build.

In scope

  • Read an explicit XML path and call PoB's existing loadBuildFromXML.
  • Return the loaded build or a deterministic error.
  • Keep the source file read-only.

Out of scope

  • UI file pickers, persistence, XML parsing, network, or model calls.
  • Changing PoB's XML format or calculation formulas.

Contract

load_xml_file(path, name) -> build | nil, error
