# Documentation History

Historical planning and implementation documents are preserved here for provenance. They are not authoritative. Current policy is defined by `AGENT.md`, `CUSTOMER.md`, `PRD_SDD.md`, and `agent/knowledge/RULE_*`.

- `completed/`: completed historical plans whose implementation details remain useful
- `superseded/`: plans whose assumptions conflict with the current external-AI, local-Bridge architecture

Each moved document is marked at its top with `Status: Historical` or `Status: Superseded`, `Authority: Not authoritative`, and the current superseding documents.
