Tool and Rule Completion Scope

Goal

Close the requested Agent Tool and PoE rule gaps using only values and traces that PoB or an explicitly versioned source can support.

In scope: Batch A only

  • get_skill_dps(build, skillIndex): read activeSkillList[skillIndex].output.TotalDPS; facts are {skillIndex,name,value}.
  • get_highest_dps_skill(build): scan numeric TotalDPS, choose the highest value, break ties by lowest skill index, and return {skillIndex,name,value}; no numeric DPS returns nil,error.
  • get_skill_breakdown(build, skillIndex): facts are {skillIndex,name,breakdown={status="calculated"|"unavailable",values={key=[scalar trace values]}}}; no recalculation.
  • get_item_modifiers(build, itemId): facts are {itemId,name?,baseName?,raw?,modLines=[{line:string,category:string}]}, using only implicitModLines, explicitModLines, enchantModLines, and craftedModLines. Missing/nonexistent itemId returns nil,error; an item with no lines returns an empty modLines array.
  • Allowed files: src/Modules/AgentTool.lua, its focused Lua self-check, and this plan. No PoB formula changes.

Out of scope

  • Changing PoB formulas, inventing simulation results, or copying whole wiki pages.
  • PoE2, UI, deployment, and model prompt changes.

Completion contract

Each Tool returns the existing envelope or nil,error; Batch A is complete when success, missing output, invalid index, and deterministic tie behavior pass self-checks. Rule and later Tool batches require separate scopes.
