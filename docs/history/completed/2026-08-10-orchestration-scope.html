Agent Orchestration

Status: Approved for implementation

Goal

Turn a user question into a deterministic intent and ordered retrieval/PoB-tool plan before any model is called.

In scope

  • Classify questions as item_alias, rule_search, pob_stat, mechanism_compare, or unknown.
  • Extract simple entities: skill name, support name, Skill Set selector, and stat terms.
  • Return ordered steps such as search_knowledge, get_projectile_count, compare_support_effect, and explain_damage_change.
  • Keep the plan JSON-serializable and deterministic.
  • Add standard-library Python self-checks.

Out of scope

  • LLM/API calls, model download, prompt generation, tool execution, UI, server, and persistence.
  • Guessing entities not present in the question.

Contract

plan(question) -> {
  intent = string,
  entities = table,
  steps = [{ tool, arguments }],
  confidence = number
}

Acceptance

  • Known Korean item query plans alias search.
  • Projectile/curse questions plan the matching PoB tool.
  • Greater Volley damage questions plan cache comparison then explanation.
  • Unknown questions return an explicit unknown plan.
