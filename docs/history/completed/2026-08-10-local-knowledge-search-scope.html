Local Knowledge Search

Status: Approved for implementation

Goal

Provide deterministic offline search over PoE1 rule JSON and Korean item aliases without a database or network service.

In scope

  • Build a versioned JSON index from existing rule and alias JSON.
  • Preserve source, patch, category, English, and Korean fields.
  • Add a standard-library Python search module with ranked results.
  • Add exact English/Korean/category/unknown-query tests.

Out of scope

  • Embeddings, vector databases, network search, RAG orchestration, model calls, or UI.
  • Changing canonical rule or alias text.

Contract

search(query, limit=10, category=None) -> list
result = { score, text, korean, category, source }

Acceptance

  • Index rebuild is deterministic.
  • English and Korean item queries return source documents.
  • Unknown queries return an empty list.
  • Stored source strings are not normalized.
