PoB Mechanism Fact Structure Implementation Plan

Goal: expose PoB's existing calculated mechanism state in one read-only Fact Envelope.

Architecture: add one Lua module that reads build.skillsTab.socketGroupList, build.itemsTab.slots, and build.calcsTab.mainEnv.player, reuses AgentTool for calculated projectile/curse facts, and marks unavailable or unsimulated areas explicitly.

Tech stack: Lua/LuaJIT, existing PoB runtime, assert-based self-checks.

Global constraints

  • Read-only; no PoB calculation edits.
  • No new dependencies.
  • Preserve PoB array order.
  • All errors use nil, error.

Task 1: deterministic contract test

Files: create tests/agent/tools/test_agent_mechanism_tool.lua.

  1. Build a fake object with socket groups, item slots, gem instances, player output, active skills, and breakdown arrays.
  2. Assert group/gem order, item name from build.itemsTab.items[build.itemsTab.slots[group.slot].selItemId], enabled, trigger, projectile, curse, and status fields.
  3. Assert missing build returns an error and missing optional values use the documented status.
  4. Run with LuaJIT and confirm the test fails before implementation.

Task 2: minimal mechanism module

Files: create src/Modules/AgentMechanismTool.lua.

  1. Validate build.calcsTab.mainEnv.player.
  2. Copy only scalar values from PoB tables.
  3. Map socket groups and gemList in original order, resolving the group slot through build.itemsTab.slots[group.slot] and build.itemsTab.items[slot.selItemId], reading only scalar item fields.
  4. Map active skills, trigger fields, scalar outputs, and shallow scalar trace arrays from player.breakdown and skill.breakdown.
  5. Call AgentTool.get_projectile_count where available and get_curse_limit once.
  6. Return not_simulated markers for actual application-order or combat sequencing without inventing calculations.

Task 3: tests and external smoke

Files: modify tests/agent/tools/test_user_build_headless.lua.

  1. Load the mechanism module after PoB's frame calculation.
  2. Assert a non-empty skill list and socket-group list when present.
  3. Print calculated/unavailable/not_simulated statuses without hard-coded patch values.
  4. Run fake, snapshot, and external Imported build tests.

Task 4: review and commit

  1. Run git diff --check.
  2. Verify no PoB calculation module changed.
  3. Commit with feat: structure PoB mechanism facts.
