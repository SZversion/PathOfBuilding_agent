Elemental Penetration Tool Scope

Goal

Expose PoB's already-calculated elemental penetration for one active skill so an Agent Tool can read it without duplicating damage formulas.

In scope

  • Initialize output.ElementalPenetration = {} per active skill and record output.ElementalPenetration[damageType] = pen for each Fire, Cold, or Lightning pass.
  • Add AgentTool.get_elemental_penetration(build, skillIndex).
  • Return a normal Agent envelope with skill index, skill name, per-element values, and PoB source references.
  • Validate build state and skill index using the existing Tool contract.

Out of scope

  • Reimplementing resistance or penetration formulas.
  • Automatic XML loading, skill-name lookup, model answers, UI, or Python runtime wiring.
  • Changing physical/chaos penetration or enemy resistance calculations.

Contract

get_elemental_penetration(build, skillIndex) -> envelope | nil, error
facts = { skillIndex, name, values = { Fire, Cold, Lightning } }

A missing value means that element was not calculated for the skill and is omitted from values; if all three are absent, return an error.

The instrumentation only stores the already-computed scalar and must not alter effective-resistance or damage calculations.
