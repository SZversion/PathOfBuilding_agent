PoB Evidence Tools

Status: Approved for implementation

Goal

Expose socket order and turn an existing PoB cache comparison into an explainable damage-change result.

In scope

  • Add get_socket_order(build, skillSetSelector, skillName).
  • Add explain_damage_change(build, skillSetSelector, skillName, supportName) as a thin wrapper over the existing cache comparison.
  • Report gem order, enabled state, output values, numeric deltas, and source references.
  • Never calculate a new formula or infer unavailable values.

Out of scope

  • Natural-language answers, model, UI, server, RAG, or database.
  • New PoE formulas or multi-support optimization.

Contract

get_socket_order(...) -> envelope | nil, error
explain_damage_change(...) -> envelope | nil, error
facts = { before, after, delta, trace }

Acceptance

  • Socket order preserves PoB gemList order.
  • Damage explanation reuses cached comparison values and identifies the changed support.
  • Fake and external LuaJIT tests pass.
