PoB Bridge Scope

Goal

Let the Python orchestration runtime call read-only Lua PoB Tools for one XML build.

In scope

  • One-shot LuaJIT subprocess bridge using JSON on stdin/stdout.
  • Build path, optional Skill Set/skill-name resolution, and existing Tool dispatch.
  • Python handler factory compatible with execute_plan.

Out of scope

  • Persistent daemon, UI, model calls, network, or concurrent requests.

Contract

stdin request: {"tool": string, "arguments": object}
stdout success: {"ok": true, "result": ToolEnvelope}
stdout failure: {"ok": false, "error": string}
command argument: XML build path

The Lua bridge calls loadBuildFromXML, then runCallback("OnFrame") before resolving a skill or invoking a Tool. Python uses a fixed timeout; timeout, non-zero exit, invalid JSON, or ok:false become RuntimeError.
